# USSD Codes (legacy)

Directory of USSD codes for mobile operators in West and Central Africa.

This repository holds the original native Android app (Java). It is archived and no longer maintained.
The app is now developed in Flutter at [netersoft/ussd-codes](https://github.com/netersoft/ussd-codes).
The new app keeps the same application id, so it ships on the [Play Store](https://play.google.com/store/apps/details?id=com.neteru.mobileussdcodex) as an update of this one.

## Project

- Application id: `com.neteru.mobileussdcodex`
- Version in this repository: 1.3.3
- Android Studio project (Gradle), `minSdkVersion` 14

The project targets the Android SDK and Gradle versions of its time and is not expected to build as is with current tools.
